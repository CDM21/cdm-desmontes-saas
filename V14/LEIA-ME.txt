COMO APLICAR

1) Extraia este ZIP dentro de:
   C:\CDM_DEPLOY

2) Abra o PowerShell em C:\CDM_DEPLOY

3) Execute:
   python .\APLICAR_CDM_V14.py

O aplicador faz backup em memória e, se algo falhar, restaura os arquivos anteriores.

4) Se aparecer:
   CDM V14 APLICADA E VALIDADA.

Rode:
   git add .
   git commit -m "V14 fundadores desmonte inteligente monitoramento"
   git push

5) Depois do deploy do Render, abra o site e teste:
- Portal do Dono > Receita
- Portal do Dono > Sistema
- Inteligência > Desmonte Inteligente
- Veículos > Visão 360
